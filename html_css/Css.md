# curly-octo-rotary-phone

**Fonctionnement du CSS : Le système de sélecteurs :**
Le CSS (Cascading Style Sheet) fonctionne avec un système de sélecteurs. Le sélecteur va **cibler** un élément HTML et lui appliquer des propriétés. Exemple : 

#titre1{
color : red;
} 
Ici on cible l'élément #titre1, ce qui va nous permettre de lui appliquer des propriétés. Dans cet exemple, nous lui attribuons une couleur (color), qui est le rouge (red). 

Le CSS fonctionne en **cascade**, les propriétés s'appliquent de haut en bas et se superposent --> Si plusieurs règles ciblent le même élément le navigateur utilise cette règle de propriété pour choisir le style final.
